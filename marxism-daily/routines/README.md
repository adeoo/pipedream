("Lesson markdown to email renderer", session_01XytEq2BeXdxPduDjHSAgEH).

To apply a change: in that session, read the file for the Routine and call
`update_trigger` with the trigger id below and the file content as `prompt`.
Do not delete or recreate a Routine.
